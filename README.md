# Marketing Campaign Performance Dashboard

An interactive marketing analytics dashboard built in Excel to transform raw campaign data into meaningful business insights. This project was developed during Week 1 of the Advanced Data Analytics Internship with the National Telecommunication Institute (NTI) in collaboration with ITIDA.

### 🛠️ Tech Stack & Tools
* **Microsoft Excel:** Dashboard design, PivotTables, and PivotCharts
* **Power Query:** Data cleaning and transformation
* **Power Pivot:** Star-schema data modeling and table relationships
* **DAX:** KPI calculations and custom measures

## 🔍 Key Features & Workflow

* **Data Engineering:** Cleaned and transformed raw datasets using Power Query before loading them into the Data Model.
* **Data Modeling:** Established relational connections between dimension and fact tables to enable cross-table filtering.
* **DAX Calculations:** Created custom measures to evaluate campaign success, including:
  * Total Spend & Budget vs. Actual Spend
  * Total Clicks & Total Impressions
  * Click-Through Rate (CTR)
  * Conversion Rate
* **Interactive Visualizations:** Built a dynamic dashboard featuring KPI cards, time-series analysis (Clicks Over Time), and categorical breakdowns (Conversions by Channel, Conversion Rate by Campaign).
* **Dynamic Filtering:** Implemented interactive slicers allowing users to filter the entire report by **Channel**, **Month**, and **Campaign Name**.

## 💡 Business Impact
This project demonstrates the ability to automate data transformation workflows and communicate business performance through advanced Excel analytics, answering key questions about marketing ROI and channel efficiency.
